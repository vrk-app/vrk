# Agent Bootstrap Archive

Этот каталог хранит bootstrap-only материалы, которые использовались для первоначальной установки и засева repo-local Codex harness.

Активный runtime workflow живет в:

- `AGENTS.md`
- `docs/roadmap.md`
- `.codex/agents/`
- `.codex/config.toml`
- `.agent/stages/`

Архив содержит:

- `bootstrap_stage.py`
- `config.toml.example`
- `assets/agents/`
- `assets/templates/`
- `codex_skill_creation_prompt.md`

Эти файлы не входят в стандартный stage-run workflow. Используй их только для ручного восстановления harness или как историческую справку о том, как он был собран.
