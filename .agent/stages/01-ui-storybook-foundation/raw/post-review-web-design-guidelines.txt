## Closed findings

- `LoginForm` now renders a semantic `<form>`, submits via Enter, keeps the submit button truthful, and separates field-level errors from a form-level server error.
- `ConsentRow` now exposes a real checkbox API for controlled and uncontrolled usage, with `aria-describedby`, `disabled`, `required`, and a single clickable hit target.
- `AuthSplitLayout` now proves the required `mobile stacked` state instead of hiding the illustration below `lg`.
- `TopBar` and `SidebarNav` now expose real controlled APIs for mobile menu state and drawer dismissal; stories prove the interactive contract and add the missing `without notifications` / `long labels` states.
- `Breadcrumbs` now marks the current item with `aria-current="page"`.
- `RequestList` now exposes a usable pagination callback, clamps impossible ranges, and proves the out-of-range state in Storybook.
- Storybook now receives the same typography baseline as the Next shell.
- The landing-page CTA no longer points to a hardcoded local loopback URL and falls back to a local runbook when no published Storybook URL is configured.
