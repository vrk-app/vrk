# VRK Web

`apps/web` is the Stage 01 Storybook-first UI foundation for VRK.

## Commands

Run from the repository root:

```bash
pnpm install
pnpm storybook
pnpm storybook:build
pnpm run web:build
pnpm run web:lint
```

The current scope is limited to reusable UI primitives, design tokens, shared story helpers, and Storybook proof surfaces. Business runtime and backend integration stay out of Stage 01.
